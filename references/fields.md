# 字段目录

以下目录列出支持的字段 ID、名称与中文表头。实际可用字段由 DLL 能力和当前文件的通道配置决定。

共 **1985 个当前字段**，覆盖 12 个映射表；保留标识和旧 ID 别名不计入字段数。

## 按子表查找

| 子表 | 字段数 | 完整 ID／名称／中文表头 |
|---|---:|---|
| `Cycle.` | 903 | [Cycle 字段表](fields-cycle.md) |
| `Step.` | 856 | [Step 字段表](fields-step.md) |
| `Rec.` | 226 | [Rec 字段表](fields-rec.md) |

请求使用十进制数字 ID。请从对应层级表选取 DLL 已识别的 ID。动态通道还须核对当前文件的实际绑定数。名称用于查表。

## 三层导出范围

| 层 | SDK 可读 ID 目录 | 直接导出上限（含动态通道） |
|---|---:|---:|
| 循环 | 903 | 903 |
| 工步 | 856 | 848 |
| 记录 | 226 | 224 |

平台和辅助通道的“全部”选项展开为有 SDK ID 的具体列。平台默认选充电、放电各 1、2 号，每侧的第 3～5 号按用户确认的范围追加。文件实际列清单由 `f.export_columns(level)` 返回。三层表另含 2 个循环组合字段、3 个工步组合字段和 7 个记录组合字段，总上限分别为 905、851、231。组合字段通过 [Python 展示接口](python-api.md) 读取。仅原始读取支持的列包括工步的 `8204/8205/8206/8209/8210/8218/8219/8220` 和记录的 `16399/16402`。
