# LANDCex 加载错误码

适用于 `GetLastLoadError` 返回的 `DWORD`。`LoadData` 返回空句柄时，向用户显示“文件名：加载失败”。需要排查时查看 Python 异常中的 `native_message` 和完整 `native_code`。码值来自当前 SDK。

| 文件读取结果（低 16 位） | 中文含义 |
|---|---|
| 0 | 无错误 |
| 1 | 无法识别文件数据格式 |
| 2 | 文件数据校验错误 |
| 3 | 不支持该文件版本 |
| 4 | 扩展文件头错误 |
| 5 | 新文件头错误 |
| 6 | 软件版本过低，无法读取该数据版本 |
| 10 | 打开文件失败 |
| 11 | 读取文件时发生异常 |
| 20 | 不支持测试中途升级并启用的文件版本 |
| 21 | 读取测试中途启用的数据版本需要升级软件 |
| 22 | SDK 提示需核实生成文件的软件是否正版 |
| 23 | 内存不足 |
| 24 | 没有数据记录，文件头可能仍可读取 |
| 25 | 文件数据错误 |
| 26 | 操作已取消 |

上表适用于高 16 位为 `0` 或正的有符号短整数。打开失败（10）和读取异常（11）的高 16 位可带 MFC 文件异常原因。保留完整码，不能仅按十进制 `10`、`11` 做相等比较。预留值没有已定义的具体解释。

| 特殊完整码（十六进制） | 中文含义 |
|---|---|
| `0xFFFE0001` | 设备校验未通过 |
| `0xFFFE0002` | 缺少设备 ID 数据库文件 |
| `0xFFFE0003` | 读取设备 ID 数据库失败 |
| `0xFFFE0004` | 设备 ID 数据库已过期 |
| `0xFFFFFFFF` | 用于接收基准循环的输出指针无效 |
| `0xFFFFFFFE` | 传给 SDK 的路径参数无效 |
| `0xFFFFFFFD` | 读取模式无效 |
| `0xFFFFFFFC` | 触发 SDK 版权检查 |
| `0xFFFFFFFB` | 数据对象分配失败，内存不足 |

特殊完整码优先于低位解释。例如 `0xFFFE0001` 在 JSON 中是 `4294836225`，表示设备校验未通过。只有 DLL 实际返回的码和说明才属于本次诊断。未知码或空说明保留原值；没有依据时只提示“加载失败”。
